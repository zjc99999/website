- **框架**：Astro 7（静态优先，默认零客户端 JS）
- **语言**：TypeScript strict（当前锁 6.0.3）
- **样式**：Tailwind CSS 4（CSS-first，无配置文件）
- **内容**：MDX / Markdown + Content Layer + Zod 构建期校验
- **写作**：Git + 编辑器 + `pnpm new:log`
- **部署**：静态托管 + 自定义域名

选它们的共同理由：简单、可替换、不把我锁进某个后台。
