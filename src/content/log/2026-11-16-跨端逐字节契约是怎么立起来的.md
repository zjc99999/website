## 先把算法钉死在纸上

MyLock 的格式规范冻结了一组参数：Argon2id m=65536 KiB、t=3、**p=4**、salt 16 B、tag 32 B；密钥包裹走 RFC 3394 AES-256-KW；HKDF 只做 Expand 并用 `wrap/password`、`manifest`、`object` 等 context 做域分离；内容用 XChaCha20-Poly1305，1 MiB 分块，每块独立 24 B nonce。

参数写出来只是第一步，真正的风险是「各端各算各的，谁也不认为自己是错的」。于是我们先用 Python PoC 生成了一份 `test-vectors.json`（13,499 B，30 个派生输出 + 13 个负向向量），把它定为**唯一逐字节契约**。

## 逐字节一致，是被 CRLF 教会的

契约文件在 `.gitattributes` 里被标成 `-text`——禁止换行归一化。原因很具体：190 处 CRLF 一旦被 Git 转成 LF，文件 SHA-256 锚（以 `07af0e8b…9939` 开头）就变了，跨平台一致性会莫名其妙地红。这类坑不踩一次根本想不到。

指纹 `d45b8659…02fa` 的算法也很克制：30 个输出按 `k=v\n` 排序拼成 UTF-8（8,254 B）再取 SHA-256。简单、确定、任何语言都能复现。

## 让契约自己守门

围绕这份向量搭了三层门禁：

1. **KAT 先行**：每个原语先过权威测试向量——RFC 9106 §5.3（Argon2）、draft-xchacha §A.3.1、RFC 3394 §4.6、RFC 5869 A.1、RFC 4231；PoC 阶段 26 PASS / 0 FAIL。
2. **负向向量**：`m=4TiB` 必须在跑 Argon2 之前就被 `E_FORMAT` 挡下（否则内存直接被打爆）；slot 互换 → `E_AUTH_FAILED`；meta 翻 1 bit → `E_DOWNGRADE`；空对象 → `E_CORRUPT`。13/13 命中。
3. **三平台 CI**：`.github/workflows/vectors.yml` 在 Windows / macOS / Linux 上跑同一份向量；Android 真机（Redmi / Android 12 / arm64）跑到 30/30 derived、13/13 negative、p=4 一致、`ok=true`。

这里守住的纪律是：**内核实现 ≠ 五端验收**。macOS / Linux 目前只是 CI 配置、尚未实跑，文档里就如实写「未实跑」，不把配置成功说成验证通过。
